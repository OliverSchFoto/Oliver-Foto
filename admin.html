03 / GOOGLE DRIVE SETUP

CONNECT YOUR PHOTOGRAPHS.

  1. Open Google Cloud Console and create a project.
  2. Enable the Google Drive API for that project.
  3. Create an API key under APIs & Services → Credentials.
  4. Restrict the key to the Google Drive API and your GitHub Pages website URL.
  5. Paste the key into googleDriveApiKey in config.js.
  6. For each album folder, set General access to Anyone with the link — Viewer.

The API key is visible in the website's public source code. It must be restricted to the Drive API and your site domain. Do not put passwords, private keys or write-access credentials in this website.
